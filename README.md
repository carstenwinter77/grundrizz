# Grundrizz

Grundriss zeichnen, einrichten und in 3D begehen. Läuft komplett im Browser, auch auf dem iPhone.

**Öffnen:** https://carstenwinter77.github.io/grundrizz/

Projekte werden im Browser des jeweiligen Geräts gespeichert. Zum Mitnehmen auf ein anderes Gerät unter „Projekte“ als Datei sichern und dort wieder laden.
